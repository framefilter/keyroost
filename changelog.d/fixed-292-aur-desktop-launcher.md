- **The AUR package `keyroost-bin` adds keyroost to the application menu.**
  It installed the programs but no desktop entry or icon, so the app could
  only be started from a terminal. It now installs the same launcher and
  icon as the Flatpak (a scalable icon and a 256px one for menus that don't
  show scalable icons). Reported by @jurjendevries. ([#292])
