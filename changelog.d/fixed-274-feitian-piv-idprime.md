- **A Feitian key that showed as an IDPrime card is known as Feitian.**
  keyroost took the PIV application of a BioPass FIDO Pro for a
  Gemalto/Thales IDPrime, with its reset switched off. A Feitian key is
  now told by its own applications, and which product it is by what the
  key reports, so `piv reset` and the app's reset work on it, the PIN
  tries show, and it is offered the key types it holds. Checked on one
  key with the command line. Contributed by @Snrat. ([#274])
